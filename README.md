# PRIME WOODEN WORK — Wood Arthouse

A premium, contemporary e-commerce experience and bespoke atelier website for **Prime Wooden Work**, an Egyptian wooden furniture and custom millwork brand founded in Cairo (1948).

Designed with a warm architectural editorial aesthetic, modern serif typography, and a full shopping suite.

## ✨ Features

- **Editorial Homepage**:
  - Full-width hero banner with *“Made in Egypt · Made to Last”* identity
  - Shop by Room category tiles (*Living Room, Dining, Bedroom, Tables, Chairs, Storage, Custom Furniture*)
  - Featured 6-piece signature collection with dual-angle hover preview & quick actions
  - *“Made for Your Space”* bespoke woodworking showcase
  - Craftsmanship lifecycle storytelling (*01 Select, 02 Shape, 03 Finish, 04 Deliver*)
  - Architectural brand story & Egyptian heritage since 1948
  - Instagram social proof gallery (`@primewoodenwork`)
  - Sophisticated footer with Cairo showroom contacts & newsletter subscription

- **E-Commerce Shop**:
  - Dynamic category filters & wood finish filter (*Oak, Walnut, Ash*)
  - Sorting by price, featured, and new releases
  - Quick view modal with instant bag additions
  - Wishlist management

- **Product Detail Experience**:
  - Multi-image gallery with thumbnail navigation
  - Timber finish swatches with live preview
  - Dimension selectors & quantity adjustment
  - In-depth specifications (Dimensions, Materials & Finishes, Delivery & Installation, Wood Care)
  - Curated pairing recommendations

- **Custom Bespoke Atelier**:
  - Step-by-step custom furniture builder
  - Specific dimensions (W × H × D cm)
  - Hardwood selection (European Oak, American Walnut, Egyptian Beech, etc.)
  - Inspiration sketch/photo upload dropzone with preview
  - Egyptian contact & governorate selector
  - Instant reference quote ticket with direct WhatsApp concierge connection

- **Bag & Checkout**:
  - Slide-out cart drawer & dedicated cart page
  - Complimentary Cairo white-glove installation progress indicator
  - Streamlined Egyptian checkout with governorate/district selectors
  - Flexible payment options: Cash on Delivery (COD), Credit/Debit Card, ValU 12-month installments, Bank Transfer
  - Order confirmation screen with generated order ID

- **Global Navigation & Search**:
  - Sticky header with announcement marquee
  - Full catalog live search overlay
  - Responsive mobile drawer menu

## 🛠 Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React**
- **Google Fonts** (*Cormorant Garamond, Cinzel, Plus Jakarta Sans*)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/dotstorydot-gif/PRIME.git

# Navigate into directory
cd PRIME

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```
